Flags images with P(AIGC) >= threshold that are at least min image size on screen in both dimensions. Decorative/background images (marked as such by the page, or shaped like a banner rather than a photo) are skipped regardless of size. Requires the local inference server running: uv run python demo/server.py.

Debug mode shows a badge on every image/video actually scored, not just the ones over threshold — green (confidently real) fading through yellow (at the threshold) to red (confidently AI), so you can sanity-check the model on things it isn't flagging, not just the ones it is.
